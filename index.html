第一章 :: INTRODUCTION

系統概述與目的

系統簡介
  • 以瀏覽器為平台的指令式文字冒險與解謎遊戲。
  • 玩家輸入指令、閱讀信件與故事文件，並調查劇情物件。
  • 使用黑白主題、文字動畫及音效營造探索氛圍。
文件目的與範圍
本文件說明系統架構、主要模組、操作流程、介面與資料設計， 供專案成員、開發人員及測試人員參考。 目前已有的功能與未來規劃會分開說明； 完整存檔與讀檔屬於未來規劃。
專有名詞
名詞 說明
CLI 命令列介面；玩家輸入文字指令的操作方式。
SPA 單頁式應用程式；遊戲在同一網頁中切換不同畫面。
View 遊戲畫面，例如終端機、故事文件或解鎖列表。

指令介面與處理設計

目前主要指令
指令 功能
simple 開啟說明信件。
k33p_1t_s1mpl3 開啟彩蛋信件頁面。
01_GR_1 開啟故事文件。

name、6、7 變更玩家或角色名稱。
title／tittle 自訂列表中的資料夾名稱。
back、exit、Esc 返回終端機或前一畫面。
指令處理流程
  1. 玩家於終端機或列表頁輸入指令。
  2. 系統移除指令前後空白並判斷指令內容。
  3. 依指令更新畫面、名稱、主題或解鎖狀態。
  4. 需要保存的部分資料寫入 localStorage。
  5. 若指令無效或格式錯誤，顯示提示訊息。
完整的 save／load 指令目前尚未實作。 未來若加入，將以瀏覽器本機保存為方向，不規劃後端 API。

第四章 :: UI / UX DESIGN

介面與使用者體驗設計

終端機首頁
顯示開場文字動畫、玩家名稱與指令輸入欄，作為主要操作入口。
故事與信件
以文件或信件版面呈現劇情，部分文字可點擊調查，並支援逐字顯示效果。
解鎖列表
將已開啟的故事項目依類別整理，玩家可從列表再次進入內容。
畫面概念：終端機
┌────────────────────────────┐
│                  [主題切換] │
│                            │
│       Welcome Player!      │
│                            │
│ > 輸入指令...              │
│                            │
│ 操作提示                   │
└────────────────────────────┘
設計原則
  • 黑白主題維持一致的復古終端機風格。
  • 指令輸入與按鈕操作並行，方便不同使用習慣的玩家。
  • 使用提示文字處理錯誤，避免彈窗中斷閱讀。
  • 音效或動畫失敗時，仍可繼續閱讀與操作。
  • 支援鍵盤快捷操作，例如 Esc 返回及主題切換快捷鍵。
第五章 :: QUALITY & SECURITY

非功能性需求與異常處理

非功能性需求
  • 可用性：提供清楚的指令提示與返回方式。
  • 穩定性：錯誤指令或音效失敗不應造成遊戲中斷。
  • 相容性：以現代瀏覽器為主要執行環境。
  • 可維護性：未來可將大型元件拆分為不同功能模組。
  • 擴充性：可新增故事內容、指令與互動物件。
安全性與異常處理
  • 系統不設置玩家帳號、密碼、登入驗證或後端 API。
  • 玩家資料由瀏覽器 localStorage 保存，不保存密碼或敏感個人資料。
  • 讀取資料失敗或 JSON 格式錯誤時，使用預設狀態繼續遊戲。
  • 音效無法載入或播放時，略過音效，不影響遊戲操作。
  • 未知指令或格式錯誤時，在介面顯示提示訊息。
  • 清除瀏覽器資料或更換裝置時，可能無法保留原有進度。
本系統為瀏覽器端單人遊戲，不需要後端伺服器、資料庫、Redis 或負載平衡。 Node.js 僅用於開發與建置階段。
第六章 :: STATUS & FUTURE PLAN

目前成果與未來規劃

目前已有功能
  • 使用 React、TypeScript 與 Vite 建立的瀏覽器遊戲。
  • 終端機風格指令輸入及多個故事畫面。
  • 黑白主題切換、開場動畫與信件逐字效果。
  • 故事物件調查及已解鎖內容列表。
  • 玩家／角色命名與部分 localStorage 保存。
  • 指定章節的雨聲、敲門聲、腳步聲及開門聲效果。
未來開發項目
  • 加入完整的本機存檔與讀檔流程。
  • 評估多存檔槽、進度重置與存檔格式版本管理。
  • 擴充故事章節、互動事件與任務內容。
  • 將指令、故事資料、狀態管理與儲存邏輯拆分為不同模組。
  • 增加指令處理、資料保存及頁面導覽的自動化測試。
  • 改善不同螢幕尺寸及鍵盤操作體驗。
開發順序建議

第一階段完成故事內容與主要操作流程；第二階段整理前端程式模組； 第三階段加入完整的瀏覽器本機存檔與讀檔功能。 本專案不規劃後端伺服器、資料庫或雲端同步。
